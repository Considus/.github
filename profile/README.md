# Considus

Considus is a small software studio in the UK. The aim is to create a small number of tools that earn their place in people's lives, made with care, priced honestly, and built to last.

Most of what's here exists because I needed it myself and, either couldn't find a solution or, couldn't find one I liked.

**[Catchlight](https://catchlight.app)** is the main project so far, a private, zero-knowledge notes and reminders app for iPhone. It's not launched yet, I'm building it in the open, and using it for my own daily notes, tasks and reminders while I do, which keeps me honest. The code is public because a privacy claim you can't inspect is just an empty promise.

There are two smaller tools here as well, built for my own workflow and shared in case they fit yours too. Both are ready to use today, **[proton-bridge-mcp](https://github.com/Considus/proton-bridge-mcp)** lets an AI assistant read and organise your Proton Mail without your mail ever leaving your machine. **[pagespeed-insights-mcp](https://github.com/Considus/pagespeed-insights-mcp)** measures site speed as the median of several runs with the spread shown, so a change smaller than the noise doesn't get read as a change.
