# Considus

Considus is a one-person software studio in the UK. The aim is a small number of tools that earn their place in people's lives, made with care, priced honestly, and built to last.

Most of what's here exists because I needed it myself and couldn't find a version I liked.

**[Catchlight](https://catchlight.app)** is the main event, a private, zero-knowledge notes and reminders app for iPhone. It's not launched yet, I'm building it in the open, and using it for my own daily notes while I do, which keeps me honest. The code is public because a privacy claim you can't inspect is just a promise.

There are two smaller tools here as well, built for my own workflow and shared in case they fit yours, and both are ready to use today. **[proton-bridge-mcp](https://github.com/Considus/proton-bridge-mcp)** lets an AI assistant read and organise your Proton Mail without your mail ever leaving your machine. **[pagespeed-insights-mcp](https://github.com/Considus/pagespeed-insights-mcp)** measures site speed as the median of several runs with the spread shown, so a change smaller than the noise doesn't get read as a change.

The website is [considus.com](https://considus.com), and support@considus.com comes straight to me.
